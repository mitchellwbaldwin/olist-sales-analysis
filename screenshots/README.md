# Olist Sales Analysis

## Overview
This project analyzes e-commerce sales data from the Olist marketplace to uncover trends in order volume, revenue growth, and geographic performance.

The analysis was performed using:
- SQL (data modeling, joins, aggregations)
- Power BI (data visualization and dashboard design)

## Business Questions Answered
- How have orders changed over time?
- How has total revenue grown over time?
- Which states generate the most orders?
- Which states generate the most revenue?
